# 성공인사이드 교육 과정 서브페이지 (/programs) 설계

작성일: 2026-08-24

## 목적

성공인사이드에 교육 과정 소개 서브페이지를 추가한다. `소스/eopla.net/eoschool.html`(EO 이오스쿨)에서 **정보 구조만** 참고하고, 강사·과정·문구는 성공인사이드 자체 콘텐츠로 새로 작성한다.

## 콘텐츠 원칙 (중요)

수집한 `eoschool.html`에는 실명 인물 30여 명이 소속·직함과 함께 들어 있다(김태용/이오스튜디오, 이택경/매쉬업엔젤스, 탈레스 테이셰이라/전 하버드 교수 등). 이들은 EO 이오스쿨 연사이며 성공인사이드와 무관하다.

- 실명 인물·소속·이력을 그대로 옮기지 않는다. 동의 없는 제휴 표기가 되고, EO의 과정 카탈로그를 그대로 복제하는 문제도 있다.
- 강사진은 **홈페이지에 이미 등장하는 가상 인물을 재사용**한다. `app/page.tsx`의 `posts`/`people` 배열에 있는 김서준·이하은·박도윤·최유진·오민재·정지우·한소연·윤태호를 그대로 강사로 쓴다. 세계관이 일관되고 실존 인물 문제가 없다.
- README에 명시된 프로젝트 방침("수집 자료는 정보 구조 참고에만 사용, 코드와 브랜드·콘텐츠는 새로 작성")과 일치한다.

## 차용하는 정보 구조

eoschool 페이지의 검증된 순서를 따른다:

1. 히어로 — 한 줄 약속 + 설명 + CTA
2. 강사진 그리드 — 이름 / 소속·직함 / 담당 과정
3. 정기 과정 — 기수제, 라이브. 과정별 설명 + 강사 + 상세 링크
4. VOD 과정 — 상시 수강. 과정별 설명 + 강사 이력 + 주요 학습 내용
5. 신청 CTA + 푸터

## 라우트

- `/programs` — 신규. 빈 `app/programs/` 폴더가 이미 존재해 의도된 경로로 판단.
- `/about` — 14:17에 소스가 삭제되어 404. 함께 복원한다. 스크린샷에 남은 다크 네이비 랜딩("당신의 성공은 기록되고 있습니까?") 방향을 참고해 재작성.

## 구조 개선 (범위 내)

현재 `app/page.tsx`에 헤더와 푸터가 인라인으로 들어 있다. 페이지가 3개가 되면 3중 복제가 되므로 공용 컴포넌트로 분리한다.

- `app/components/SiteHeader.tsx` — 클라이언트 컴포넌트. 모바일 메뉴 상태를 자체 보유. props: `active`(현재 메뉴 강조), `onWrite`(글쓰기 모달 핸들러, 없으면 홈으로 링크).
- `app/components/SiteFooter.tsx` — 정적.
- 홈도 이 컴포넌트를 쓰도록 전환하고, 전환 후 홈이 그대로 렌더되는지 확인한다.

그 외 리팩터링은 하지 않는다.

## 콘텐츠 설계

### 정기 과정 (4개)

| 과정 | 설명 축 | 강사 |
|---|---|---|
| 첫 고객 100명 만들기 | 고객 문제 정의 → 가설 수립 → 노코드 MVP 검증 | 김서준, 이하은 |
| 사업계획서 완성 워크숍 | 아이디어를 투자자가 읽는 문서로 | 정지우, 윤태호 |
| 재구매를 만드는 CX 설계 | 첫 구매가 아닌 두 번째 구매 설계 | 김서준, 최유진 |
| 1인 기업 생존 부트캠프 | 현금흐름·파이프라인을 숫자로 관리 | 오민재 |

### VOD 과정 (5개)

| 과정 | 설명 축 | 강사 |
|---|---|---|
| AI 업무 자동화 설계 | 도구보다 업무 흐름 먼저 | 박도윤 |
| 광고비 0원 그로스 마케팅 | 고객이 모여 있는 한 곳을 깊게 | 이하은 |
| 가격 경쟁에서 벗어나는 브랜딩 | 기억될 한 문장 만들기 | 최유진 |
| 창업가의 재무 기준 세우기 | 투자자 관점의 의사결정 기준 | 윤태호 |
| 읽히는 글을 쓰는 법 | 경험을 설득력 있는 글로 | 한소연 |

## 스타일

- `globals.css`의 네이비·골드 토큰을 그대로 사용: `--green:#101827`, `--lime:#d8ad45`, 골드 악센트 `#bd8e2f`/`#e2b84f`/`#a77820`.
- 페이지 전용 CSS는 `app/programs/programs.css`로 분리해 페이지에서 import한다 (삭제된 about 페이지가 쓰던 라우트별 CSS 패턴과 동일).
- 반응형 분기는 기존과 맞춘다: 900px, 620px.

## 성공 기준

- `/programs`, `/about`, `/` 모두 200 응답.
- 콘솔 에러 없음.
- 브라우저 스크린샷에서 히어로·강사진·정기 과정·VOD 과정 섹션이 네이비·골드 테마로 렌더됨.
- 620px 폭에서 레이아웃이 깨지지 않음.
- 실명 실존 인물이 페이지에 등장하지 않음.
